# Agentic AI Resilience Lab — v1.0 Scope Freeze

Status: FROZEN
Frozen: 2026-08-20

## Target

v1.0 is a bounded deterministic simulation-based technical demonstrator for failure propagation, traceability, evidence checking, containment, and recovery in a fixed multi-stage workflow.

## MUST

- Fixed eight-stage workflow.
- One authoritative workflow definition.
- One authoritative scenario registry.
- Eight predefined controlled scenarios.
- Expected outcomes defined before implementation hardening.
- Deterministic execution.
- Structured traces.
- Explicit evidence states.
- Deterministic evidence checking.
- Bounded authority checking.
- Measurable propagation.
- Simulated context containment.
- Explicit trusted-state rollback and deterministic recovery.
- Automated expected-vs-actual evaluation.
- Pytest coverage of defined v1.0 behaviours.
- One reproducible evaluation command.
- GitHub Actions CI.
- Versioned evaluation results.
- Explicit limitations and claim boundaries.
- v1.0 tag only after tests, evaluation, CI, and documentation pass.

## SHOULD

- Preserve the existing Streamlit interface as a demonstration layer.
- Make Streamlit consume the canonical simulation implementation.
- Retain the rule-based failure classifier with non-probabilistic terminology.
- Persist representative traces.
- Add concise terminology and architecture documentation.
- Verify the existing Docker build.

## NOT NEEDED FOR v1.0

- Live LLM agents.
- Production infrastructure actions.
- FastAPI.
- Databases.
- Cloud deployment.
- Kubernetes.
- Trained ML classifiers.
- LLM-as-a-judge.
- Vector databases.
- Real attack execution.
- Regulatory compliance claims.
- GATE-5G integration.
- DevSecOps integration.
- Telecommunications-specific extensions.
- Large scenario corpora.
- Claims of production or real-world resilience.

## Claim Boundary

v1.0 does not prove multi-agent safety, prevent real attacks, validate production agent systems, establish regulatory compliance, or demonstrate real-world infrastructure resilience.

The project remains a simulation-based technical demonstrator.
